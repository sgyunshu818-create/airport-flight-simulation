# UI 美化与动画增强报告

## 修改范围

- 登录页：重构为“沉浸式任务入口 -> 登录控制台”的两阶段体验，保留原有 `/login` 提交地址、`username` 与 `password` 字段、演示账号和后端登录流程。
- 全局视觉系统：在 `app.css` 中补充统一 motion token、焦点态、面板入场、指标卡悬浮、表格行反馈、状态标签和按钮反馈。
- 导航体验：在 `app.js` 中按当前路径自动高亮侧边导航，不需要后端额外传参。
- 响应式：补充 1180px、860px、520px 以下的布局约束，覆盖桌面、平板和移动端。
- 静态资产：新增登录页空间任务背景图 `login-orbit-bg.png`，配合 canvas 粒子形成 NASA 风格的克制空间感。

## react-bits 借鉴方式

当前项目是 Spring Boot + Thymeleaf + 静态 CSS/JS，不是 React 技术栈，因此没有直接引入 `DavidHDev/react-bits` 的 React 组件依赖，避免增加运行时复杂度。

采用的借鉴点：

- `Particles` 类背景思路：使用原生 canvas 实现低密度星点与轨迹感。
- `AnimatedContent` / reveal 类思路：使用 CSS keyframes 与统一 motion token 实现页面、面板、指标卡入场。
- `ClickSpark` / interaction effect 思路：登录入口按钮加入 launch 状态、扫光与空间转场。
- 可复制组件理念：所有效果落在本项目现有 `app.css` 与 `app.js`，便于维护与继续扩展。

## 动画设计

- 登录页初始状态只展示全屏空间任务动画和中心引导按钮，不直接暴露输入框。
- 点击“进入任务控制”后，先触发 launch 反馈，再过渡到登录控制台并自动聚焦账号输入框。
- 登录后页面只使用轻量动画：导航高亮、卡片悬浮、面板入场、表格行反馈和按钮状态反馈。
- 加入 `prefers-reduced-motion` 处理，用户系统开启减少动态效果时会自动降低动画。

## 验证方式

- 检查模板 UTF-8 内容，确认没有 replacement character。
- 运行 `mvn test`：30 个测试通过，0 failures，0 errors。
- 运行 `mvn package -DskipTests`：打包成功。
- 启动本地服务并检查关键路由、静态资源、登录页。
- 使用 Playwright 截图检查桌面、平板、移动端关键视口，包括 1440px、1024px、768px、390px。
- 登录点击态验证：点击引导按钮后 `is-auth-visible=true`，表单 `action=/login`，账号与密码字段仍存在，账号输入框自动聚焦。
- 横向溢出检测：1024px 仪表盘、768px 仿真页、390px 登录表单态均无页面级横向溢出。

## 注意事项

- 登录默认演示账号仍为 `admin / 123456`。
- 没有引入大型前端依赖；后续如迁移到 React，可再直接复用 react-bits 组件。
- 当前动画以可读性和性能优先，避免廉价霓虹、过度滤镜和影响数据扫描的动效。
