# UI 美化与动画增强报告

## 修改范围

- 登录页：重构为“沉浸式任务入口 -> 登录控制台”的两阶段体验，保留原有 `/login` 提交地址、`username` 与 `password` 字段、演示账号和后端登录流程。
- 全局视觉系统：在 `app.css` 中补充统一 motion token、焦点态、面板入场、指标卡悬浮、表格行反馈、状态标签和按钮反馈。
- 导航体验：在 `app.js` 中按当前路径自动高亮侧边导航，不需要后端额外传参。
- 响应式：补充 1180px、860px、520px 以下的布局约束，覆盖桌面、平板和移动端。
- 静态资产：新增登录页空间任务背景图 `login-orbit-bg.png`，配合 canvas 粒子形成 NASA 风格的克制空间感。

## react-bits 借鉴方式

当前项目是 Spring Boot + Thymeleaf + 静态 CSS/JS，不是 React 技术栈，因此没有直接引入 `DavidHDev/react-bits` 的 React 组件依赖，避免增加运行时复杂度。

采用的借鉴点：

- `Particles` 类背景思路：使用原生 canvas 实现低密度星点与轨迹感。
- `AnimatedContent` / reveal 类思路：使用 CSS keyframes 与统一 motion token 实现页面、面板、指标卡入场。
- `ClickSpark` / interaction effect 思路：登录入口按钮加入 launch 状态、扫光与空间转场。
- 可复制组件理念：所有效果落在本项目现有 `app.css` 与 `app.js`，便于维护与继续扩展。

## 动画设计

- 登录页初始状态只展示全屏空间任务动画和中心引导按钮，不直接暴露输入框。
- 点击“进入任务控制”后，先触发 launch 反馈，再过渡到登录控制台并自动聚焦账号输入框。
- 登录后页面只使用轻量动画：导航高亮、卡片悬浮、面板入场、表格行反馈和按钮状态反馈。
- 加入 `prefers-reduced-motion` 处理，用户系统开启减少动态效果时会自动降低动画。

## 追加优化：B 端专业感降噪

根据后续评审意见，进一步从“深色科幻大屏”收敛到更克制的专业调度系统风格：

- 字体系统：新增 `--font-sans` 与 `--font-mono`，航班号、时间、指标数字、表格数据、地图标牌使用等宽字体与 `tabular-nums`，减少数字跳动和视觉松散。
- 色彩系统：降低青色、蓝色、绿色的饱和度，减少大面积高亮，只保留在关键状态和交互反馈中使用。
- 面板材质：将强渐变和外发光改为低透明玻璃材质、极细边框、轻微内发光和更浅的阴影。
- 数据密度：增加指标卡、面板头部、面板内容和表格单元格的留白，让信息扫描更稳定。
- 时间轴：将进度条从粗渐变条调整为细线单色，降低视觉噪声。
- 机场态势图：改为线框雷达风，跑道、滑行道、机位和飞机标牌都减少立体感和外发光，更接近仿真/空管系统。
- 状态标签：改为更小、更低透明度的胶囊标签，避免和核心数据争夺视觉焦点。

## 追加优化：全景 HUD 与交互深度

根据最新评审建议，将运行概览从传统后台网格升级为“全景机场态势图 + 悬浮 HUD + 底部仿真控制台”：

- 全景视角：`dashboard.html` 重构为 `simulation-shell`，左侧为极简图标导航，中间为全屏机场态势画布，右侧为异常/资源/事件 Inspector，底部为时间轴 Dock。
- 地图操作：在 `app.js` 中增加鼠标滚轮缩放、中键/右键拖拽平移、视角预设切换。
- 上下文菜单：地图右键弹出磨砂玻璃操作菜单，预留查看详情、强制延误、分配跑道、跟随视角等操作入口。
- 快捷键：支持 `Space` 暂停/继续视觉仿真、`→` 单步反馈、`1/2/3` 切换全局/航站/跑道视角、`F` 收起/展开 Inspector。
- 时间控制：底部控制台增加 `1x/2x/5x/10x/MAX` 倍速状态切换，为后续真实仿真倍速联动预留前端入口。
- 事件生命感：新增底部 Live Event Ticker，模拟实时事件流播报。
- 决策图层：新增热力图、冲突连线、天气层开关，前端先实现可视化与交互底座，后续可接后端冲突检测、天气容量降级和 WebSocket 实时事件。
